Mini Synthesizer

The Mini Synthesizer is a compact, electronic musical instrument designed to work like a real synthesizer, featuring 37 piano keys and hands-on controls.

It uses an ESP32 microcontroller to process key inputs and generate electronic sounds, melodies, basslines, and sound effects.

The project aims to support different instrument sounds, such as piano and organ, along with creative synthesizer tones in a portable, budget-friendly design.
